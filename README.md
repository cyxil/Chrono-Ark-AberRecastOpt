# Chrono-Ark-AberRecastOpt

超时空方舟（Chrono Ark）Mod - 装备/遗物重铸优化

## 功能

- 删除营地炼金台的使用次数限制（无限次重铸）
- 支持**单个装备或遗物**直接重铸，无需放满两个槽位
- 装备重铸结果品质+1（原版逻辑），单物品重铸保持原品质
- 遗物重铸出现4个随机遗物供选择

## 安装

将 `AberRecastOpt` 文件夹放入游戏的 `Mod` 目录下：

```
Chrono Ark/
└── Mod/
    └── AberRecastOpt/
        ├── Assemblies/
        │   ├── 0Harmony.dll
        │   └── ChronoArkMagicAnvilDev.dll
        ├── ChronoArkMod.json
        └── Example.png
```

然后在游戏内启用mod即可。

## 依赖

- Harmony 2.10.x（已内置）
